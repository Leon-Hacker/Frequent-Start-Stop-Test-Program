# 2 路串口继电器控制器

使用 PySide6 和智嵌物联自定义协议控制 2 路串口继电器模块。

## 运行

```bash
conda run -n mylab python main.py
```

打开程序后：

1. 选择串口，默认波特率为 `9600`，地址为 `1`。
2. 点击“打开串口”。
3. 程序会自动轮询继电器状态，默认间隔 `200ms`。
4. 使用每路“打开/关闭”按钮控制继电器。

## 验证

```bash
conda run -n mylab python -m unittest -v
```

测试覆盖读状态帧、单路控制帧、状态应答解析、校验错误和地址不匹配。
